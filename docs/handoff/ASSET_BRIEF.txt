IDENTITY
Early-computer road-trip satire with green handheld-game illustration and a phosphor terminal frame. The loaded, slightly ridiculous van is the visual anchor. Preserve Pacific Northwest conifers, wet roads, cramped cafes, sticker-covered equipment, earnest travelers and absurd roadside commerce. Let the humor come from props and situations. Small interface assets need stronger silhouettes and less noise than full scenes.

CURRENT UI COLORS (observed CSS)
Background #000000; main green #00FF00; secondary green #00AA00; body text #00CC00; cyan information #00DDDD; warning #FFAA00; danger #FF6666; success #00FF66; dead/disabled gray around #666666/#555555. Font is Courier Prime with Courier fallbacks. Existing JPEGs contain many green shades, not a strict four-color sprite palette.

PROPOSED ART PALETTE (recommendation, not extracted exact colors)
Near-black #07110A, dark green #18331B, middle green #426E35, highlight #A4C96A. Keep bright phosphor accents in the interface, separate from the illustration. Use one outline weight and a controlled highlight direction. Optional amber/red/cyan in the UI must be paired with a shape or label, so meaning does not depend solely on color.

Optional 4x nearest-neighbor preview. Start with two rolling frames, not a large animation library.
5. Five party/status symbols: healthy, sick, injured, deceased and selected. Base 24x24 or 32x32. Pair each icon with readable name/health/status text; deceased must remain visually distinct after any later action.
6. One reusable travel environment, ideally a 640x360 illustrated master with a safe central 4:3 crop. Separate the van if using animation. Keep route/date/weather overlays in the interface. Optional sky/forest/road layers only when they serve the chosen implementation.

Seven route establishing scenes: guest-room/co-op departure, highway rest stop, irony-laden motel, viral roadside attraction, DeFi gas-station backroom, food-cart pod, Portland arrival. Nine encounter vignettes matching actual events: doomscrolling, NFT fair, food poisoning, breakdown, good drizzle, heatwave, Free Box, ISP outage, and pandemic critical encounter if retained. Reuse coherent scenery and character designs. Create a distinct loss illustration as well as victory. Start with the faulty slots; do not blindly regenerate every existing JPEG.

SCENE FILE CONTRACT
Use 640x360 (16:9) PNG/WebP masters or 1024x576 illustrations with controlled downsampling. Keep important faces/props in the central 75% width and 80% height; provide a 4:3-safe crop. The size is a proposed delivery specification, not the current app's format. Existing files are mainly 1024x1024 JPEGs and two erroneous 409x1024 screenshots. Background scenes are opaque. Portraits, inventory icons and van sprites have true alpha transparency, with no fake checkerboard and no colored matte. Flat icons must read at 24-32 displayed pixels.

SPRITE CONTRACT
Fixed cells and transparent gutters are required. Each exported icon is its own file with a stable id. Animation frames share silhouette scale and baseline. Provide frame names and pixel rectangles in JSON. True pixel-art assets use a fixed base grid and nearest-neighbor integer scaling; conceptual AI pixel-art output should be inspected and cleaned before being treated as a production sprite sheet. Do not rely on a generative model to place an exact animation grid or render exact text.
