# Selected splash artwork validation

October 2, 2026. The user requested three polished intro alternatives, then selected the first generated image, **The Road Ahead**. All three original 1536×1024 opaque RGB PNGs are preserved in [graphics-v5](../handoff/graphics-v5/README.md), with [exact prompts and provenance](../handoff/graphics-v5/generation.json). ## Preservation and integration

The three masters are unchanged copies of the built-in image generator's native outputs. Recorded SHA-256 hashes confirm their source identity. Each has exactly five travelers, a loaded green van, Oregon scenery and no embedded title or readable lettering. The [independent artwork review](splash-candidates-v5/art-review.md) records the alternatives' composition tradeoffs.

`prepare-assets.py` now sources `title` from `docs/handoff/graphics-v5/title-road-ahead.png` with crop `None`. The obsolete fixed title sign repair is removed. The old source JPEG and all previous masters remain preserved. No CSS, markup, game data, rules or saves changed.

`npm run assets` passed. Only the two title WebPs changed: 1536×1024 at 255,494 bytes and 960×640 at 118,676 bytes. The other 80 derived assets are unchanged. The manifest records the selected source hash, dimensions, crop and empty repair list. The generated scene contact sheet was visually inspected.

## Screen previews

All three alternatives were rendered through the existing live title and controls at 390×844, 414×896, 430×932, 1440×900 and 844×390. Temporary WebP exports matched the pipeline settings; browser interception substituted each alternative before navigation. [Candidate report](splash-candidates-v5/report.json): 15 cases, 150 checks, zero failures or browser errors. [Preview index](splash-candidates-v5/README.md) keeps all three reviewable.

The selected image was then checked separately through real app URLs without interception. Response hashes match the selected production exports. [Integrated report](splash-candidates-v5/selected-report.json): five cases, 55 checks, zero failures or browser errors. Checks cover responsive dimensions, loaded images, overflow, live heading, minimum control sizes, keyboard reachability and opening normal setup with Start.

The primary phone and desktop pairs were visually inspected: all five travelers and the van remain visible, and the existing title and controls remain legible. [Phone screenshot](splash-candidates-v5/selected-title-390x844.png) and [desktop screenshot](splash-candidates-v5/selected-title-1440x900.png) preserve the integrated result.
