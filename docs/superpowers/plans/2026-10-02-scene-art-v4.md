# Scene artwork v4 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Generate, preserve, and integrate the five scenes requested in the v4 brief.

**Architecture:** New immutable PNG masters feed the existing deterministic asset pipeline. Only region and encounter scene references change; gameplay stays the same.

**Tech Stack:** Built-in image_gen, Python asset pipeline through uv, native JavaScript, existing Node and Playwright checks.

**Spec:** [Five-scene brief](../../art/2026-10-02-scene-brief-v4.md), [AGENTS.md](../../../AGENTS.md), and asset specification section 7.

## Global constraints

- Opaque landscape masters, 1536×1024 (3:2).
- Preserve original artwork, existing encounter ids, and all gameplay numbers.
- Every prompt includes the brief's unchanged style and exclusion blocks.
- Road backdrops have a horizontal road and no people or vehicles; encounters have no van or lettering.
- Save masters in `docs/handoff/graphics-v4/` with README and exact generation provenance. Never edit accepted masters.
- Regenerate `app/assets/` only with `npm run assets`.
- Use the current checkout on `codex/scene-art-v4`; no publish or push is part of this request.

## Review focus

- Compare all five outputs to existing green scene art; check signs, screens, and props for lettering.
- Validate silhouettes and wordless gags at 390px, 414px, 430px, and 1440px.
- Check short phone landscape encounter crops, which clip image sides, as well as portrait/desktop vertical crops.
- Check the new roads through the existing pines/outskirts crop, zoom, and foreground road overlays.
- Verify provenance, derived manifest hashes, build/offline delivery, and preservation of unrelated assets.
